Sensor Pareto: which signals separate failing wafers?

Ranked by Cohen's d between failing and passing wafers. With 440 sensors, some will look different by chance, so each is checked two ways: a 5% false discovery rate, and the largest effect seen when pass/fail labels are shuffled 500 times. Only sensors 60, 104 and 511 pass both.

Process drift: why static limits go stale

Loading...

In the later half, passing wafers trip more than twice as many static limits as in the reference period, and failing wafers no longer stand out. The process drifted, so limits and models have to be refreshed as new wafers are tested.

Which wafers to inspect first?

Every method was trained or calibrated on the first 784 wafers and scored on the later 783 (37 fails, base rate 4.7%). All variants tried are shown. Average precision is the area under the precision-recall curve; random scores about the base rate.
